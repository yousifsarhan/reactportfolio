React Portfolio

A clean and lightweight personal portfolio website built using React, JavaScript, HTML, and CSS, and deployed with GitHub Pages.

Live Website:
[https://yousifsarhan.github.io/reactportfolio/](https://yousifsarhan.github.io/reactportfolio/)



Overview

This project is a front-end portfolio website designed to present my profile, skills, and projects in a simple and professional way.

It is intentionally built without a backend to keep it fast, easy to maintain, and easy to deploy. The focus of this project is clean structure, clarity, and presentation.



Features![Uploading Screenshot 2026-01-09 at 12.16.30 AM.png…]()


* Personal introduction / profile
* Skills and technologies section
* Projects showcase with links
* Clean and minimal UI
* Responsive layout
* Deployed and publicly accessible via GitHub Pages



Tech Stack

* React – UI components
* JavaScript – logic and interaction
* HTML – structure
* CSS – styling and layout
* GitHub Pages – hosting and deployment

Running the Project Locally

Option 1: Using VS Code (Recommended)

1. Open the project folder in **VS Code**
2. Install the **Live Server** extension
3. Right-click `index.html`
4. Select **Open with Live Server**



Option 2: Using Terminal

bash
python3 -m http.server 5500


Then open:


http://localhost:5500




Deployment

This project is deployed using GitHub Pages.

Deployment steps:

1. Push changes to the `main` branch
2. GitHub Pages automatically publishes the site
